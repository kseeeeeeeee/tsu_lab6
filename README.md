## Цель работы

Изучить основы веб-программирования на Python с использованием Flask и FastAPI, освоить создание REST API, работу с шаблонами Jinja2 и интеграцию SQLAlchemy для взаимодействия с базой данных.

## Выполненные задания

### 1. Средняя сложность № 4 — Страница с таблицей данных
**Файл:** `lab6/table_app.py`

Создано Flask-приложение, отображающее HTML-страницу с таблицей студентов, предметов и оценок. Для формирования страницы используется шаблон Jinja2.

### 2. Средняя сложность № 6 — FastAPI «Hello»
**Файл:** `lab6/fastapi_hello.py`

Создано простое приложение FastAPI с маршрутом главной страницы, возвращающим приветственное сообщение в формате JSON.

### 3. Средняя сложность № 10 — Простой REST API для списка задач
**Файл:** `lab6/tasks_api.py`

Реализован REST API для управления задачами. Поддерживаются получение списка задач, создание новой задачи, получение задачи по идентификатору и удаление задачи.

### 4. Повышенная сложность № 5 — REST API для заметок
**Файл:** `lab6/notes_api.py`

Создан REST API для работы с заметками. Реализованы операции создания, просмотра, изменения и удаления заметок.

### 5. Повышенная сложность № 9 — Интеграция SQLAlchemy
**Файл:** `lab6/sqlalchemy_app.py`

Реализовано взаимодействие FastAPI с базой данных SQLite с помощью SQLAlchemy. Поддерживаются создание, просмотр и удаление задач. Проверено сохранение данных после перезапуска приложения.

Файл базы данных: `lab6/tasks.db`.

## Результат

Все пять заданий выполнены, приложения запущены и проверены. Основные функции REST API протестированы через Swagger UI. Интеграция SQLAlchemy с SQLite проверена, сохранение данных подтверждено.
